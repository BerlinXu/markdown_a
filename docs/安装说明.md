# 安装与文件保护

不需要编译：下载 `release/纸墨Markdown.apk`，传到手机，按系统提示安装。这是已签名、关闭调试的 Release APK，适用于 Android 8.0 及以上；文件摘要见同目录 `SHA256SUMS.txt`。

1.1.4 使用 versionCode 13，并沿用此前测试 APK 的签名证书，支持相同签名安装的覆盖升级。自行编译或其他渠道的 APK 若使用不同证书，通常不能直接覆盖。不要为解决签名冲突直接卸载：应用目录和未导出的草稿会被清理，应先导出重要文档。

阅读页「导出文档」复制原文件字节；编辑页「另存为」导出当前编辑内容；「导出原文恢复副本」导出上一次写入前的原始字节。分享发送文件授权，只有用户选择的接收应用获得临时读取权限。

来源只读时，原文件不会自动写回。保存冲突时保留草稿，可另存后比较版本。非 UTF-8 文档乱码时，在阅读菜单指定源编码后再编辑。卸载前备份；恢复副本不等于长期备份。

新装或从早期版本升级会加入《从计算机到人工智能》图文长文，正文与配图可离线阅读。已有个人文档不覆盖；用户删除新版示例后不自动补回。导出 Markdown 不自动打包配图，跨设备阅读需同时复制对应图片目录。

横屏默认全屏，轻点顶部中央箭头唤出工具栏，再点或停止触摸约 6 秒收起。当前版本未使用下载网页，也不需要在电脑上运行临时文件服务器。
