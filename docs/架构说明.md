# 架构与行为边界

## 阅读与编辑

`core/MarkdownParser.kt` 将文本解析为带源行号的块与行内节点；`ReadingBlocks` 将过大的段落、列表、代码和表格拆成阅读单元。`ReaderActivity` 以 RecyclerView 复用视图，后台解析串行化，过期结果取消。解析仍保留全文和语法树，不是流式处理无限文档。

`EditorViewModel` 持有文本和差量编辑历史，通过互斥锁串行保存；保存成功才允许依赖成功结果的返回。统计与预览延迟计算，预览限制单元和文字规模。输入法保持原生 EditText 行为。

`LandscapeChrome` 只在阅读和编辑横屏安装：隐藏系统栏、标题和格式栏，顶部中央浮签切换；展开时安排一个 6 秒延迟任务，触摸与失去窗口焦点时暂停。生命周期暂停/销毁清理计时，无轮询。竖屏不安装控制器。

## 文件、恢复与图片

`DocStore` 管理应用目录与 SAF 来源，以原文字节摘要发现覆盖冲突。应用文件采用临时文件与原子替换；SAF 只能按提供方能力写入并回读校验，不能承诺跨应用原子比较交换。写前保留恢复副本，未保存编辑另有私有草稿。

`SafeIo` 和 `TextCodec` 限制输入并处理编码、BOM 与换行。`ReadingState` 保存位置与书签；设置重置不清除阅读状态。文件分享采用 FileProvider 临时授权。

`ImageLoader` 使用固定工作线程、缓存上限、下载大小与解码像素上限。图片接近屏幕时加载；网络图片默认关闭，只允许 HTTPS；相对文件和目录访问限定在文档目录或用户授权范围内。

## 内置内容

`assets/sample.md` 和 `assets/sample-images/` 是可独立阅读的图文源。`SampleDocuments` 在 IO 线程一次性安装当前内容版本：先写独立配图目录，再用不覆盖同名文件的导入方式生成文档，最后持久化安装状态。旧版 `seeded` 不阻止新示例升级，已存在或改过的用户文件不删除。

用户删除新版示例后不会每次重建。删除文档也不自动删除图片目录，因为其他文档可能引用这些图片。失败时回滚本次创建的文件，未完成的安装可再次尝试。

`docs/illustrations/` 保存八幅图的编辑源；`tools/render-sample-diagrams.py` 可重新生成。图片是教学示意，不是史料照片；正文引用的资料不随包分发。

## 明确的限制

- 自有 Markdown 语法子集，不声称完整 CommonMark/GFM 一致性；脚注支持单行定义。
- 文档、源行、递归深度、扫描预算、图片字节和像素均有上限，具体值见 README 与代码常量。
- 自动编码识别存在歧义；原编码不能表示新增字符时拒绝保存。混合换行可能统一为主风格。
- 不能保证突然断电或强制终止前最后一小段输入已持久化；卸载会清理私有草稿及恢复副本。
- 公式、Mermaid、PDF、同步、加密不包含在当前核心。
